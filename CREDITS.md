# Credits and asset sources

Каждый сторонний ассет, добавленный в проект, записывается сюда: файл, источник, автор, лицензия, дата добавления.

## Фаза 1

Сторонних ассетов нет. Всё содержимое создано для проекта или сгенерировано кодом:

| Что | Как получено | Лицензия |
|---|---|---|
| Геометрия полигона, мишени, персонаж меню, модели оружия и рук | процедурно, `TrainingRangeBuilder`, `HumanoidModel`, `ViewModel` | собственная |
| Текстуры поверхностей, декали, превью карт, иконки интерфейса | процедурно, `ProceduralTextures`, `MapArt`, `MenuIcon` | собственная |
| Все звуки (выстрелы, шаги, попадания, перезарядка, интерфейс) | синтез в коде, `SoundBank` | собственная |
| Шрифт интерфейса | встроенный шрифт Godot по умолчанию | входит в Godot (MIT / OFL) |
| Названия оружия | оригинальные | собственная |
