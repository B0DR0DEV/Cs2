# Credits and asset sources

Каждый сторонний ассет, добавленный в проект, записывается сюда: файл, источник, автор, лицензия, дата добавления.

## Фаза 1

Сторонних ассетов нет. Всё содержимое создано для проекта или сгенерировано кодом:

| Что | Как получено | Лицензия |
|---|---|---|
| Геометрия полигона, мишени, модели оружия и рук | процедурно, `MeshFactory`, `BlockoutMapBuilder`, `ViewModel` | собственная |
| Текстуры поверхностей, декали, прицел, интерфейс | процедурно, `ProceduralTextures` | собственная |
| Все звуки (выстрелы, шаги, попадания, перезарядка) | синтез в коде, `ProceduralAudio` | собственная |
| Шрифт интерфейса | встроенный шрифт Unity `LegacyRuntime.ttf` (с системным фолбэком) | входит в Unity |
| Названия оружия | оригинальные | собственная |
