# Strike Zone

Мобильный тактический шутер 5×5 (рабочее название). **Godot 4.7 (.NET, C#)**, сначала Android.
Сборка APK — в GitHub Actions **без регистраций, аккаунтов и секретов**.

Статус: **фаза 0 (архитектура) + фаза 1 (оффлайн-ядро) + главное меню**.
Документы: [архитектура](docs/ARCHITECTURE.md), [отчёт фазы 1](docs/PHASE1_REPORT.md).

## Как получить APK

1. Откройте вкладку **Actions** репозитория → последний запуск **Tests and Android APK** (запускается на каждый push в `main`; вручную — кнопка **Run workflow**).
2. Дождитесь зелёной галочки (≈10 минут).
3. Внизу страницы запуска скачайте артефакт **StrikeZone-Android** — внутри `StrikeZone.apk`.
4. Установите на телефон (Android 8+, 64-битный процессор), разрешив установку из неизвестных источников.

APK подписан отладочным ключом, который создаётся при сборке.

## Что внутри

- **Главное меню**: верхняя панель (выход, настройки, логотип, вкладки, валюты, профиль, друзья), персонаж в 3D-сцене, лобби с местами для группы, вкладка «Играть» с режимами, сеткой карт с галочками, «Выбрать все / Снять все», регионом и большой кнопкой запуска; инвентарь (выбор снаряжения), статистика, настройки, экраны магазина и пропуска.
- **Полигон**: мишени на 5–70 м, стрейфящие и приседающие мишени, секция прострелов (дерево, металл, кирпич, бетон), полоса движения (прыжок с приседом, лестницы, вышка 10 м).
- **Механики**: движение в стиле Source (контр-стрейф, ходьба, присед, воздушный стрейф, лестницы, урон от падения, замедление от попаданий); 23 оружия с фиксированными паттернами отдачи; урон по зонам, броня и шлем, падение урона с дистанцией, прострел стен; трассеры, декали, гильзы; синтезированные звуки с окклюзией.
- **Управление**: мультитач (плавающий джойстик, свайп-обзор, две кнопки огня с прицеливанием, прыжок, присед, прицел, перезарядка, оружие) и клавиатура/мышь.

## Структура

```
src/Core      чистый C# без движка: движение, оружие, урон, пробитие, конфиги
src/Game      слой Godot: меню, полигон, игрок, оружие, эффекты, звук, HUD, ввод
config        баланс оружия, движения и материалов (JSON)
tests         NUnit-тесты ядра (dotnet test)
docs          архитектура и отчёты
```

## Локальная работа

- Godot **4.7.2 .NET** (https://godotengine.org/download) + .NET SDK 8. Откройте `project.godot`, нажмите Play.
- Тесты ядра: `dotnet test tests/StrikeZone.Core.Tests/StrikeZone.Core.Tests.csproj`.
- Экспорт APK локально: установите шаблоны экспорта .NET, JDK 17 и Android SDK, затем `godot --headless --export-debug "Android" build/StrikeZone.apk`.

## Управление на ПК

WASD — движение, Shift — шаг, Ctrl/C — присед, Пробел — прыжок, ЛКМ — огонь (клик захватывает курсор), ПКМ — прицел/тяжёлый удар ножом, R — перезарядка, F — осмотр, 1/2/3 — оружие, Q — предыдущее, Esc — меню матча, B — арсенал.
