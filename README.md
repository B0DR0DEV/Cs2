# Strike Zone

Мобильный тактический шутер 5×5 (рабочее название). Unity 6.3 LTS, URP, C#. Сначала Android.

Текущий статус: **фаза 0 (архитектура) + фаза 1 (оффлайн-ядро стрельбы и движения)**.
Архитектура и план — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), отчёт о фазе 1 — в [docs/PHASE1_REPORT.md](docs/PHASE1_REPORT.md).

## Что есть в фазе 1

Полигон, построенный в коде:
- линия огня с мишенями на 5–70 м, приседающая мишень, две стрейфящие;
- секция прострелов: дерево, лист металла, кирпич, бетон, двойная деревянная стена;
- полоса движения: прыжок, прыжок с приседом, ящики, лестница, пандус, лестницы-стремянки, вышка 10 м для урона от падения;
- полосы поверхностей для сравнения шагов.

Механики: движение в стиле Source (трение, ускорение, контр-стрейф, воздушный стрейф, присед, ходьба, лестницы, урон от падения, замедление от попаданий); 23 оружия с фиксированными паттернами отдачи, точностью первого выстрела, разбросом от движения/прыжка/приседа; урон по зонам, броня и шлем, падение урона с дистанцией, прострел стен; трассеры, декали, гильзы, звуки (синтезированы в коде); сенсорное управление и клавиатура/мышь; динамический прицел, оверлей паттерна отдачи, статистика точности, настройки.

## Структура

```
Assets/StrikeZone/Core     — чистый C# без UnityEngine: движение, оружие, урон, пробитие (то же ядро пойдёт на сервер)
Assets/StrikeZone/Game     — слой Unity: полигон, игрок, оружие, эффекты, звук, HUD, ввод
Assets/StrikeZone/Editor   — генерация URP-ассета, материалов, сцены, настроек Android; сборка APK
Assets/StrikeZone/Tests    — EditMode-тесты ядра и конфигов
Assets/Resources/Config    — баланс: weapons.json, rules.json (правится без перекомпиляции)
docs/                      — архитектура, отчёты фаз
```

## Сборка APK в GitHub Actions

1. Добавьте секреты репозитория (**Settings → Secrets and variables → Actions**):
   - `UNITY_EMAIL`, `UNITY_PASSWORD` — учётная запись Unity;
   - `UNITY_LICENSE` — содержимое файла лицензии `Unity_lic.ulf`. Personal-лицензия бесплатна: войдите в Unity Hub и активируйте её, после чего файл появится здесь:
     - Windows: `C:\ProgramData\Unity\Unity_lic.ulf`
     - macOS: `/Library/Application Support/Unity/Unity_lic.ulf`
     - Linux: `~/.local/share/unity3d/Unity/Unity_lic.ulf`
2. Сделайте push в `main` или запустите workflow вручную (**Actions → Tests and Android APK → Run workflow**).
3. По окончании скачайте артефакт **StrikeZone-Android** со страницы запуска — внутри `StrikeZone.apk`.

APK подписан отладочным ключом, его можно установить на телефон напрямую (разрешите установку из неизвестных источников). Для релизной подписи добавьте секреты `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASS`, `ANDROID_KEYALIAS_NAME`, `ANDROID_KEYALIAS_PASS`.

## Локальная работа

1. Установите Unity **6000.3.27f1** с модулем Android Build Support.
2. Откройте папку репозитория в Unity Hub.
3. Выполните меню **Strike Zone → Setup Project** (создаст URP-ассет, шаблоны материалов, сцену `Assets/Scenes/Main.unity`, настройки Android).
4. Нажмите Play. Полигон строится автоматически.
5. Сборка: **Strike Zone → Build Android APK** или из командной строки:
   ```
   Unity -batchmode -quit -projectPath . -buildTarget Android \
         -executeMethod StrikeZone.EditorTools.BuildScript.BuildAndroidCI \
         -customBuildPath build/Android/StrikeZone.apk
   ```
6. Тесты: **Window → General → Test Runner → EditMode → Run All**.

## Управление

| Действие | Сенсор | Клавиатура/мышь |
|---|---|---|
| Движение | левый плавающий джойстик (слабое отклонение — шаг) | WASD, Shift — шаг |
| Обзор | свайп по правой половине или по кнопке огня | мышь (клик — захват курсора, Esc — отпустить) |
| Огонь | ОГОНЬ справа или слева | ЛКМ |
| Прицел / тяжёлый удар ножом | ПРИЦЕЛ | ПКМ |
| Прыжок / присед | ПРЫЖОК / ПРИСЕД | Пробел / Ctrl или C |
| Перезарядка / осмотр | ПЕРЕЗ. / ОСМОТР | R / F |
| Оружие | 1, 2, НОЖ | 1, 2, 3, Q — предыдущее, колесо — следующее |
| Арсенал / настройки | кнопки вверху слева | B / F10 |
